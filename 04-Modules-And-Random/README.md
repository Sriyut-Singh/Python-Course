# 📘 04 — Modules & the `random` Library

**Author:** Sriyut Singh

A look at Python's module system and two useful standard-library modules: `calendar` and `random`. Understanding modules is the bridge between "just Python syntax" and using the wider Python ecosystem (which becomes essential once you get to NumPy/Pandas).

## 📂 What's Inside

| Notebook | What it covers |
|---|---|
| `lec-01-modules-calendar.ipynb` | What a module is and how `import` works, followed by hands-on use of the `calendar` module — printing calendars, checking leap years, and related calendar utilities. |
| `lec-02-random-library.ipynb` | The `random` module — `random.random()`, `random.randint()`, `random.randrange()`, `random.choice()`, and how randomness is used inside small programs. |
| `lec-03-random-library-part-2.ipynb` | More `random` module practice — additional functions and use-cases building on Part 1. |

## 🧠 Key Concepts Practiced

- Importing and using standard-library modules
- The `calendar` module for date-related tasks
- The `random` module for generating random numbers/choices

## ▶️ How to Run

```bash
jupyter notebook
```
No installation needed — `calendar` and `random` are part of Python's standard library.
