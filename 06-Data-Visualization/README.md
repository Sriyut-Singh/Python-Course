# 📘 06 — Data Visualization

**Author:** Sriyut Singh

Turning numbers into pictures — the plotting libraries every AI/ML workflow relies on to explore and present data: **Matplotlib** and **Seaborn**.

## 📂 What's Inside

| Notebook | What it covers |
|---|---|
| `lec-01-matplotlib.ipynb` | Core Matplotlib plotting — line plots with `plt.plot()`, titles and axis labels, styling (color, linestyle, linewidth), and plotting multiple lines on the same chart. |
| `lec-02-seaborn.ipynb` | Getting started with Seaborn for statistical plotting, built on top of Matplotlib for cleaner, more informative charts. |

## 🧠 Key Concepts Practiced

- Line plots and chart styling in Matplotlib
- Titles, axis labels, colors, and line styles
- Plotting multiple series on one figure
- Introductory Seaborn plotting

## ▶️ How to Run

```bash
pip install numpy pandas matplotlib seaborn jupyter
jupyter notebook
```
