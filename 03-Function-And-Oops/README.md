# 📘 03 — Functions & OOP

**Author:** Sriyut Singh

Moving from writing straight-line scripts to organizing code into reusable **functions** and, further, into **objects and classes**. This is where Python code starts feeling more structured.

## 📂 What's Inside

| Notebook | What it covers |
|---|---|
| `lec-01-functions.ipynb` | Defining functions with `def`, calling functions, `return` values vs `print` output, function IDs, passing arguments, and the `pass` statement inside a function body. |
| `lec-02-oops.ipynb` | Object-Oriented Programming basics — what a class is ("a blueprint for the object"), creating classes, defining attributes/methods, creating objects (instances), and using them together. |

## 🧠 Key Concepts Practiced

- Function definition, calling, and return values
- Arguments and parameters
- Difference between `print()`-ing and `return`-ing a value
- Classes as blueprints for objects
- Creating and using class instances

## ▶️ How to Run

```bash
jupyter notebook
```
No external libraries needed — pure Python standard syntax.
