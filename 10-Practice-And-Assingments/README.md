# 📘 10 — Practice & Assignments

**Author:** Sriyut Singh

A mixed bag of practice notebooks and homework assignments collected along the way — this is where concepts from all the earlier folders get tested with real problem statements. Expect a wider variety of topics per file compared to the more focused folders above.

## 📂 What's Inside

| Notebook | What it covers |
|---|---|
| `lec-01-practice-1.ipynb` | A simple bank-login style practice program (ID/PIN check). |
| `lec-02-practice.ipynb` | An "age game" using the `datetime`/`date` module to calculate age from a birth date, plus other general practice. |
| `lec-03-practice-notebook-2-return.ipynb` | Practice focused on the `numpy` module and functions that `return` values. |
| `lec-04-practice-notebook-3.ipynb` | Further general practice notebook. |
| `lec-05-practice-file-4.ipynb` | More practice — number/string manipulation exercises. |
| `lec-06-practice-file-5.ipynb` | Nested-loop pattern printing exercises (diamond/star patterns). |
| `lec-07-practice-assignment-1.ipynb` | Assignment: numbers divisible by 7 but not multiples of 5, reversing first/last name, and sphere volume calculation. |
| `lec-08-practice-assignment-2.ipynb` | Assignment: implementing custom `myreduce()` and `myfilter()` functions (mimicking Python's built-in `reduce`/`filter`), plus list comprehension exercises. |
| `lec-09-practice-assignment-3.ipynb` | Formatted output practice using `.format()` — printing personal details (name, age, address) in different formats. |
| `lec-10-home-assignment-2.ipynb` | Homework on calculating percentages/grades from subject marks (English, Maths, Science, Hindi, Social Science). |
| `lec-11-home-assignment-3.ipynb` | Homework covering Celsius-to-Fahrenheit conversion and a prime-number checker. |
| `lec-12-home-assignment-4.ipynb` | Homework on finding the area of a circle from user input. |
| `lec-13-assignment-1.ipynb` | Another general assignment notebook applying earlier concepts. |
| `lec-14-math-practice.ipynb` | Quick math-focused practice problems. |

## 🧠 Key Concepts Practiced

- Applying core Python (conditionals, loops, functions) to word problems
- Using `datetime` for date-based calculations
- Custom re-implementations of built-in functions (`reduce`, `filter`)
- Formatted string output (`.format()`)
- Simple geometry/physics/math formulas translated into code

## ▶️ How to Run

```bash
pip install numpy
jupyter notebook
```
Most notebooks here only need core Python and, occasionally, `numpy`. This is a good folder to revisit after finishing the topic folders (`01` through `09`) as a self-test.
