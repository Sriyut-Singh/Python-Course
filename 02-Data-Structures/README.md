# 📘 02 — Data Structures

**Author:** Sriyut Singh

Python's built-in data structures — the containers you'll use to hold and organize data in almost every program you write. This folder builds directly on `01-python-basics`.

## 📂 What's Inside

| Notebook | What it covers |
|---|---|
| `lec-01-list.ipynb` | Lists in depth — indexing, slicing, concatenation, repetition, mutability, `max`/`min`, list comprehensions, nested lists (2D-style access), and list methods (`append`, `extend`, `index`, `insert`, `pop`, `remove`, `reverse`, `sort`, `copy`). Also includes early Hangman-game experiments built using list/string indexing. |
| `lec-02-tuple.ipynb` | Tuples — creation, indexing, immutability, and the operations that are (and aren't) allowed on them compared to lists. |
| `lec-03-set.ipynb` | Sets — uniqueness, set operations (union, intersection, difference), and common set methods. |
| `lec-04-dictionary.ipynb` | Dictionaries — key-value pairs, accessing/updating values, dictionary methods, and looping over keys/values/items. |
| `lec-05-slicing.ipynb` | Slicing syntax `[start:stop:step]` applied across strings, lists, and other sequences. |
| `lec-06-slicing-task.ipynb` | A short focused practice task applying slicing concepts from the previous notebook. |

## 🧠 Key Concepts Practiced

- Mutable vs immutable collections (list vs tuple)
- List comprehensions and nested list indexing
- Set theory operations in Python
- Dictionary key-value manipulation
- Sequence slicing `[start:stop:step]`

## ▶️ How to Run

```bash
jupyter notebook
```
No external libraries needed — everything here uses Python's built-in types (plus `random` in a couple of Hangman experiments).
